Développement de Web API (.NET/Entity Framework)

J'ai pu développer cette compétence dans le cadre du projet client de ma 2ème année, où j'ai dû concevoir et implémenter une API web en utilisant la technologie .NET couplée avec Entity Framework. Cette partie du projet m'a permis de maîtriser la création d'interfaces programmatiques permettant la communication entre différentes applications. J'ai appris à structurer une API REST, à gérer les requêtes et les réponses, ainsi qu'à manipuler les données à l'aide d'Entity Framework qui facilite l'interaction avec la base de données en adoptant une approche orientée objet.
